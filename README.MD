## 📌 What I Learned Today

### 1. Machine Learning (The Big Picture)
Teaching computers to learn patterns from data instead of hard-coding rules.
- **Types:** Supervised, Unsupervised, Reinforcement
- **Core idea:** Data → Model → Prediction → Evaluation → Improve

### 2. Linear Regression
Predicts **continuous values** by fitting the best-fit line through data.
- Equation: `y = mx + b`
- Loss = Mean Squared Error (MSE)
- Use case: predicting price, temperature, sales

### 3. Logistic Regression
Predicts **probabilities** to classify outcomes (yes/no, spam/not-spam).
- Output between 0 and 1 using the **sigmoid** function
- Threshold (usually 0.5) decides the class
- Use case: fraud detection, disease prediction

### 4. Evaluation Metrics
A model is only as good as how you measure it.
- **Accuracy** — overall correctness
- **Precision** — of predicted positives, how many were right?
- **Recall** — of actual positives, how many did we catch?
- **F1 Score** — balance between precision & recall
- **Confusion Matrix** — the full picture

### 5. Decision Trees
Splits data step-by-step like a flowchart that learns.
- Each node = a question, each branch = an answer
- Easy to interpret, prone to overfitting (fix with pruning)
- Foundation for Random Forests
